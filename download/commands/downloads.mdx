---

This category has no slash commands of its own. It's the persistent button on the panel message
that `/downloads-setup` posts — the entry point every regular member actually uses.

<Info>
  Looking for the admin side? See [Administration](/download/commands/administration) for
  `/downloads` and [Configuration](/download/commands/configuration) for `/downloads-setup`.
</Info>

<AccordionGroup>
  <Accordion title="📥 Browse Downloads — Open the download panel">
    Not a slash command — this button lives on the panel message itself, and keeps working across
    bot restarts.

    Clicking it opens a private, ephemeral browsing session only the clicking member can see:
    pick a category, then a product, and receive your link or file. It never edits the shared
    panel message.

    **Permission:** Download access — see
    [Installation & Permissions](/download/installation-permissions)

    Within that session, **🔍 Search** filters products by name, **Prev**/**Next** page through
    results, **◀ Back** returns to the category list, and **Close** dismisses the session. See
    [Download Center](/download/features/download-center) for the full flow.
  </Accordion>
</AccordionGroup>
